# Security policy

## Supported versions

Security fixes are applied to the latest tagged Jot Library release.

## Report a vulnerability

Please use GitHub’s private **Report a vulnerability** form in the repository’s Security tab. Include the affected version, reproduction steps, impact, and any proposed mitigation. Do not open a public issue for an unpatched vulnerability.

The plugin accepts no anonymous writes and uses WordPress capabilities and nonces for administrator actions. Reports about URL validation, metadata requests, CSV import/export, permissions, redirects, or unintended disclosure of draft/private entries are especially useful.
